# Tab Mover & Merger 🌐

A powerful Google Chrome extension designed to help you organize your browsing chaos. Effortlessly move tabs by domain to a new window, merge multiple windows, or quickly jump between your open windows.

## ✨ Features

### 🖱️ Context Menu Actions

Right-click anywhere on a page to access these quick tools:

- **Move this domain's tabs to a new window (Current Window):** Finds all tabs with the same domain in your _current_ window and moves them to a new window.
- **Move this domain's tabs to a new window (All Windows):** Scans _all_ open Chrome windows for tabs matching the current domain and consolidates them into a single new window.
- **Merge all windows to current:** Collects every single open tab from every window and moves them into your current focused window.

### 🧩 Extension Popup

Click the extension icon for an interactive workspace manager:

- **Move by Domain:** See the current tab's domain and how many matching tabs will be moved, then move them from this window or from all windows.
- **Interactive Window Preview:** View a list of all open windows with their tab counts and active tab favicons.
- **Quick Jump (Focus):** Click on any window in the preview list to instantly focus/switch to that window.
- **Merge All Windows:** Bring every tab into the current window directly from the popup.
