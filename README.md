# Tab Split & Merger 🌐

A powerful Google Chrome extension designed to help you organize your browsing chaos. Effortlessly split tabs by domain into a new window, merge multiple windows, or quickly jump between your open windows.

## ✨ Features

### 🖱️ Context Menu Actions

Right-click anywhere on a page to access these quick tools:

- **Move this domain's tabs to a new window (Current Window):** Finds all tabs with the same domain in your _current_ window and moves them to a new window.
- **Move this domain's tabs to a new window (All Windows):** Scans _all_ open Chrome windows for tabs matching the current domain and consolidates them into a single new window.
- **Merge all windows to current:** Collects every single open tab from every window and moves them into your current focused window.

Moving tabs by domain opens the new window on the tab you were using most recently.

### 🧩 Extension Popup

Click the extension icon for an interactive workspace manager:

- **Move by Domain:** See the current tab's domain and how many matching tabs will be moved, then move them from this window or from all windows. The new window opens on the tab you were using most recently.
- **Move this tab:** On another window's row, **Move** puts the tab you are on into that window and focuses it there.
- **Merge one window:** **Merge** on a window row pulls that window's tabs into the current window. **Merge All Windows** still brings in every other window.
- **Interactive Window Preview:** View a list of all open windows with their tab counts and active tab favicons.
- **Quick Jump (Focus):** Click a window name in the preview list to instantly focus that window.
- Moving a tab or merging between a normal window and a private window is unavailable.
